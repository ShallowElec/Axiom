# 05 · 路线图：先把地基做成产品的一部分

> 状态：设计基线，不承诺日历时间。每个阶段都必须留下 schema、测试和可演示路径；**没有“只做视觉”的里程碑。**

本阶段只交付 Trace/Scene 抽象与可运行的 2.5D 层叠、平铺原型；完整 3D 编辑/折叠与完整公式编辑器后置。

## 起点与顺序

精确有理数、表达式、11 个模板、分块组合、2D 逐帧剧场、语义检查器、运算手册已可运行；调试台、2.5D/平铺视图、多项目切换、KaTeX 公式基础、typed 槽位结构实验已有初版，95 项测试通过。值级 Trace、项目文件/仓库 revision、任意嵌套 typed 公式编辑器、MX/AD 仍未完成。

```text
M0 地基 → M1 调试台+Scene ─┬→ M2 项目/仓库 → M3 公式构建器
                            └→ M4 值系统+MX → M5 可微算法 → M6 微积分/优化/NN
```

M4 可与 M2/M3 并行；M5 同时依赖 M1/M4。M6 的方向从 M1 起就预留位置（tensor 形状、图节点、循环展开、dtype 元数据）。

## 阶段与验收

| 阶段 | 范围 | 验收（必须发生） |
|---|---|---|
| **M0 地基** | 冻结 Run/Value/Trace/Scene 契约；注册表与 worker 骨架；迁移框架；import 边界检查；性能/无障碍基线 | ≥5 个算子跑通 `RunRequest→Trace→Value`；注册表元数据可被调试台消费；core 无 DOM 依赖；既有核心/注册表测试不回归；新增序列化/迁移测试；冷启动/单帧/拖动基线入仓 |
| **M1 调试台+Scene** | 函数选择、参数区、运行；输出/原始 Trace/Storyboard/Scene；2D/层叠/平铺切换；选中同步 | 任选函数改参运行，五视图同一 `runId`；渲染器只用 Scene 数据；切换视图保留事件位置与选中值；Trace 可导出；错误显示部分事件；键盘主流程与 altText 可用 |
| **M2 项目/仓库** | 项目文件打开/保存/导入；左轨项目与资产；公式/算法仓库；恢复快照；撤销/重做；引用图 | 新建→保存→重开一致；条目 revision 化，旧固定 revision 不被改写；删除引用给出列表；损坏/旧版本不丢原文件；撤销作用于命令；1000 值项目打开 <500ms |
| **M3 公式构建器** | typed AST + 槽位；KaTeX 只读；模板迁移；结构编辑；拖拽吸附；键盘/IME/无障碍；仓库实例化 | 11 模板全 AST 化且旧表达式可解析；matmul/det/inv 可从空完成；形状/dtype 错误在运行前可读；拖拽与键盘等价；XSS 测试通过；AST 往返等价 |
| **M4 值系统+MX** | Value/DType；q/f16/f32/f64；MXFP4/6/8/INT8；cast receipt；多后端；值/Trace 序列化 | E2M1 全码值、E8M0 边界、E5M2 inf/NaN、各格式 max/min/subnormal 与规范一致；量化报告饱和/NaN；拒绝 `0xFF` scale；跨家族需显式 cast；序列化往返稳定 |
| **M5 可微算法** | 前向/反向 AD、核心 VJP、梯度 Trace、算法块/循环展开、状态机动画、折叠层、构造历史、语义色 | 6 类核心 VJP 通过有限差分/符号对拍；奇异 det 用 adjugate；rref/rank 明确拒绝；MX STE 显式留痕；梯度可从结果定位；三视图共享值引用；单帧仍 <8ms |
| **M6 微积分/优化/NN** | 符号后端、导数/积分/极限（受限）、优化、神经网络公式管线、tensor/dataflow、3D 层叠/层折叠、平铺合成 | 符号求导与 AD 可比较，不可判定显式失败；小规模优化可回放；小型网络前向/反向及每层 Trace 可查；形状/广播显式；>3 维进属性/小倍数；3D 可折叠且有 2D 回退；完整 3D 编辑不在本阶段 |

## 通行门禁

每个阶段必须：**可演示**（真实工作台操作）、**可验证**（契约测试/错误路径）、**可迁移**（版本+fixture）、**可回退**（新视图/后端可关）、**可访问**（键盘主路径+文本回退）。不满足不进入下一阶段；未稳定契约的视觉原型不能合并为事实层。视觉回归不能替代数据测试。

## 风险

| 风险 | 缓解 |
|---|---|
| 先视觉后事实，返工 | M0/M1 门禁；Scene 只消费数据 |
| schema 频繁变动 | 稳定 ID、版本、迁移 fixture；未持久化前再冻结 |
| MX/低精度错误 | 规范码值表、边界 fixture、独立实现对拍 |
| BigInt/MX 卡顿 | Worker、预算、取消、虚拟化，避免全量重算 |
| AD 在不可微点“假装可导” | 显式错误、STE 开关、对拍 |
| 公式编辑器范围失控 | 先槽位式，再自由结构；KaTeX 只读 |
| 依赖许可/版本变化 | 锁 tag、复核 LICENSE、可替换 adapter |
| 无障碍后补 | 每场景 altText/表格回退，键盘验收 |
| Electron 打包/签名拖延 | 早期 smoke 和多平台构建 |
| 小团队并行过多 | 严守 M0→M1→M2/M4，未稳契约不合并 |

## 决策记录

**已决定**：先 M0 事实层、再 M1 调试闭环，然后扩展视觉/仓库；M3 先槽位式 typed AST，不追求任意自由 WYSIWYG；M4 的 MX/浮点显式 profile；M5 的 AD 与教学故事共享 Trace；完整 3D 编辑与完整公式编辑器后置。

**待定**：注册表静态还是可安装；项目容器 JSON 还是 zip；符号后端自研还是接 Compute Engine；优化/NN 是否是独立产品面；发行渠道与签名/公证策略。
