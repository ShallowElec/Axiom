# EP01 色卡（待确认）

- 背景：纯白 `#FFFFFF`
- 文字：只允许黑 `#0B0B0B` 与天蓝系
- 不引入第三种色相；不铺渐变、不发光、不做彩色底托。

| 角色 | 色值 | 用途 |
|---|---|---|
| INK | `#0B0B0B` | 正文、标题、规则线 |
| SKY 700 | `#1F6F9C` | 小字、来源、数据；白底对比 5.5:1 |
| SKY 500 | `#40A6D6` | 大字/标题强调（≥32px）；白底 2.7:1，不能做正文 |
| SKY 300 | `#8FD3F0` | 大字、装饰、底纹；不能做正文 |
| SKY 100 | `#D9F1FB` | 极浅底、分隔 |
| PAPER | `#FFFFFF` | 纯白背景 |
